# Contributing

Open an issue with a small input, expected output, actual output and the compiler version. Keep private data out of reports.

Run `npm ci`, `npm test`, `npm run test:acsv` and `npm run build` before opening a pull request. Changes to language behavior need examples, compatibility notes and meaningful tests. Documentation examples should execute against the compiler.

Review should focus on CSV compatibility, determinism, diagnostics, resource bounds and browser/Node parity.
