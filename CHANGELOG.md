# Changelog

## 0.6.1 — 2026-11-20

- Update creator links and social metadata to @made_by_chris.
- Update the published README and display the current package version on the About page.

## 0.5.0 — 2026-11-19

- Add keyword/function examples and separate feature and use-case groups.
- Update user-facing recipes to ZROW 0.3 parenthesized syntax.
- Add JavaScript, Node.js, CLI and HTTP integration tabs.
- Use canonical compiler, CLI, error and editor identifiers and storage names.
- Accept only csv/zrow input modes and .zrow recipe files. Remove obsolete aliases and draft bridges.

## 0.4.0 — 2026-11-19

- Add ZROW 0.3 named text enums and enum column validation.
- Add explicit seeds, uniform/integer/normal generators, random and weighted selection, and bounded geographic coordinates.
- Add captured UTC clock helpers and fixed reference-time configuration.
- Document generator semantics and add customer, location, measurement and dated-event examples.
- Add a language overview below the browser editor.
- Include the parenthesized syntax introduced in the previous source release.

## 0.3.0 — source release

- Add ZROW 0.2 parenthesized declarations, directives and implicit default assignments.
- Preserve explicit 0.1 parenthesized literal data and existing @ directives.
- Add a mixed generated/literal CSV example to the editor gallery and language documentation.

## 0.2.1 — 2026-11-19

- Move the canonical site to zrow.majaku.com and the repository to made-by-chris/zrow.
- Redirect the old site while preserving paths, queries and API methods.
- Migrate existing browser drafts to the new origin.
- Simplify the editor footer to one centered row of text links.

## 0.2.0 — 2026-11-19

- Publish the compiler as zrow-js with the zrow CLI.
- Add optional ZROW 0.1 language declarations with legacy recipe compatibility.
- Add the general-purpose example gallery and version validation tests.

## 0.1.0 — 2026-11-19

- Preserve literal CSV and require explicit recipe execution.
- Add named defaults, row overrides, typed output and validation.
- Provide a local editor, CLI, library and bounded conversion API.
- Publish reference documentation and reproducible examples.
