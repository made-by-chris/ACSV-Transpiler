The CSV programming language

ZROW is the CSV programming language for creating and storing tabular data. It lets people and language models describe large datasets with a small amount of text. Rows can be written directly as CSV or generated from sequences, formulas and shared values.

A ZROW document represents a table or a collection of named tables. It contains two basic structures:

  • Columns give each field a name and an optional type, such as text, integer, number, boolean, date or a named enum.
  • Rows contain values in column order. A row can be an ordinary comma-separated record or the result of a generation rule.

Columns and rows

A column declaration begins with (cols and ends with ). Column names are separated by commas. A type follows its column name after a colon: id:int declares an integer column named id. An enum defines a named list of allowed text values.

A literal row uses CSV notation. Commas separate fields; double quotes surround fields that contain commas, line endings or quotes. A quote inside a quoted field is written twice. Literal rows can appear alongside generated rows in the same document.

Defaults and generators

An assignment such as (role=member) sets a default for subsequent rows. (rows 100) generates 100 rows from the current defaults. (row role=admin) generates one row with an override. Overrides apply to the rows that request them.

# ZROW 0.4
(enum Status "new","active","paused")
(seed 42)
(cols id:int,status:Status)
(id=seq(),status=choice(Status))
(rows 1000)

This document produces 1,000 numbered rows. Each status is selected from the enum. The seed makes the random choices reproducible. Other generators provide numeric and date sequences, repeated lists, bounded coordinates and random distributions. Date and time helpers share one reference instant, which can be fixed in the document.

Output and implementations

ZROW compiles to ordinary CSV or typed JSON. Column types and enum values are checked during compilation. Row-count and unique-key assertions can check the resulting table. The version declaration identifies the language used by the document.

The reference implementation runs in browsers and Node.js. A JavaScript package and command-line tool, a conversion API and the MIT-licensed source are available. See the language reference and examples for the full syntax.

Parameters, functions and related tables

Parameters provide typed inputs with defaults. Functions name reusable expressions. Table blocks can select values from earlier tables and validate foreign keys. Export a selected table as CSV or the complete dataset as JSON. See examples and the full rules.
